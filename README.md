# Gergely Hajdu — academic website

This folder is ready for GitHub Pages and contains no build step or framework.

## Publish

1. Create a new GitHub repository and upload all files in this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public URL after deployment finishes.

To edit the site, change `index.html`. Visual styles are in `style.css`; the portrait and CV can be replaced while keeping their current filenames.
